IMPORTANT SECURITY NOTE
This is a browser-based prototype. The demo owner password and business data are stored on the website/browser.
Do NOT use this version for real customer payments or real financial data on a public website.

For a real production store, use a secure backend / WordPress + WooCommerce:
- secure owner accounts
- database
- real orders from all customers
- proper online payments
- backups
- permissions
- courier/payment integrations

HOW TO PREVIEW
1. Unzip the folder.
2. Open index.html in Chrome/Edge.
3. Click Owner to test the private dashboard.

HOW TO PUBLISH THIS PROTOTYPE
Upload the complete folder to a static host such as Netlify, Cloudflare Pages or GitHub Pages.
For a real e-commerce launch, migrate this design into WordPress + WooCommerce rather than using the prototype for live payments.
